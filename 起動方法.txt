========================================
  http://localhost:3000 で見る方法
========================================

【方法1】Cursor のターミナルから（おすすめ）
-----------------------------------------
1. Cursor でこのフォルダを開いた状態にする
2. メニュー「ターミナル」→「新しいターミナル」を開く
3. 次のコマンドを入力して Enter：

   npm start

4. 「Serving!」や「localhost:3000」と表示されたら、
   ブラウザで http://localhost:3000 を開く

5. 終了するときはターミナルで Ctrl+C を押す


【方法2】エクスプローラーから
-----------------------------------------
1. このフォルダ（yuki_juku_lp202602）をエクスプローラーで開く
2. アドレス欄に「cmd」と入力して Enter（ここでコマンドプロンプトが開く）
3. 次のコマンドを入力して Enter：

   npm start

4. 「Serving!」と表示されたらブラウザで http://localhost:3000 を開く


【うまくいかないとき】
-----------------------------------------
・「npm は認識されていません」と出る
  → Node.js をインストールしてください
  → https://nodejs.org/
  → インストール後、Cursor を一度閉じて開き直す

・「port 3000 is already in use」と出る
  → すでに別のアプリが 3000 番を使っています
  → そのアプリを終了するか、別のポートを使う必要があります
